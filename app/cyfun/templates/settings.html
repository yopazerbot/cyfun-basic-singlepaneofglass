Backup

{% for grp in groups if grp.g.key == 'backup' %}{{ group_form(grp) }}{% endfor %}

What a backup holds

  • The database: assessment, registers, risk assessment, users, activity log and these settings, with stored secrets still encrypted.
  • Evidence files and connector snapshots.
  • Not .env. Restoring needs a server with the same CYFUN_SECRET_KEY, which also encrypts the backup file.

Backups on the server live in the data volume next to the database. The OneDrive copy is the off-host copy; it holds only the encrypted file.

Claude

{% for grp in groups if grp.g.key == 'claude' %}{{ group_form(grp) }}{% endfor %}

What Claude receives

  • The requirement, its CCB goal and guidance, the current score and justification.
  • Metadata of linked documents, evidence and open actions, the titles of other register documents, and the latest automated checks.
  • Names, e-mail addresses, device names and account lists are replaced by placeholders before sending and restored in the answer.
  • The content of an evidence file only when it is marked "Claude may read this file" on the Evidence page. Text inside PDFs and images is sent as it is.

Requests go from this server to api.anthropic.com over HTTPS. Anthropic's commercial terms for the API govern retention and use of the data; check your organisation's agreement. Every review and every decision is in the activity log.
