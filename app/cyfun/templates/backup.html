Backup and restore

A backup holds the database (assessment, registers, users, activity log and the Settings page values, secrets still encrypted) and the evidence files and connector snapshots. It is one file encrypted with the server key CYFUN_SECRET_KEY: restoring it needs a server with the same key. Environment settings (.env) are not included; keep .env with the key in your password manager.
