# Security policy

Report vulnerabilities privately through GitHub Security Advisories on this repository ("Report a vulnerability"). Do not open a public issue for security problems.

Include the version or commit, steps to reproduce and the impact you see. You will get an acknowledgement within five working days and a fix or a mitigation plan as soon as the issue is understood.

Supported: the latest commit on `main`. Dependency updates arrive through Dependabot; the CI image scan fails on fixable critical and high findings.

The security model of the application is described in docs/security.md.
